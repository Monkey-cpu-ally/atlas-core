# ATLAS Design Codex v1

## Mission
Build what does not yet exist.

ATLAS design combines engineering, science, art, craftsmanship, nature, culture, and user intent into a coherent original design language.

## Core Principles
1. Function before decoration.
2. Complexity should be hidden from the user when possible.
3. Materials must make sense for the object's purpose.
4. Shape language must communicate function and identity.
5. Every component should appear intentional.
6. Technology and nature may inform each other through biomimicry and systems thinking.
7. Premium does not mean excessive; craftsmanship and precision create value.
8. Designs should belong to the same ATLAS world without becoming visually identical.
9. Historical and contemporary creators are studied for principles, never copied as templates.
10. Engineering feasibility, safety, maintainability, and manufacturability must be considered before a concept is promoted beyond exploration.

## ATLAS Visual DNA
- Layered construction with readable hierarchy.
- Visible function where it improves understanding.
- Controlled mechanical detail rather than visual noise.
- Strong silhouettes.
- Purposeful material contrast.
- Handcrafted warmth balanced with advanced technology.
- Organic geometry where nature provides a functional advantage.
- Restrained luxury.
- Symbols should carry meaning.

## AI Responsibilities
### Minerva
Protects knowledge quality, material logic, environmental integration, cultural context, color, composition, biomimicry, and world-building.

### Hermes
Protects engineering logic, mechanisms, electronics, manufacturing, maintainability, structural integrity, system architecture, and technical feasibility.

### Ajani
Protects identity, personal style, clothing, product presence, luxury, symbolism, branding, leadership language, and visual discipline.

### Council
Challenges assumptions and synthesizes the final direction. Disagreement should be recorded when technically or creatively meaningful.

## Design Review Gates
Every serious ATLAS concept should be reviewed for:
- purpose
- originality
- engineering feasibility
- safety
- manufacturability
- maintainability
- material logic
- usability
- visual hierarchy
- ATLAS identity
- sustainability where relevant
- cost awareness
- evidence quality

## Inspiration Vault Rule
A dropped reference is not an instruction to reproduce it. ATLAS should identify why the reference is useful, extract transferable principles, connect those principles to verified knowledge, and create a distinct ATLAS solution.

## HUD Rule
The ATLAS HUD should use as few conventional buttons as practical. Prefer direct manipulation, drag-and-drop, radial/ring navigation, voice, context-aware actions, and AI orchestration. The interface should expose intent while hiding unnecessary operational complexity.

## Memory Rule
ATLAS must preserve provenance. Facts, user ideas, AI hypotheses, external research, experiments, and validated results must remain distinguishable.

## Evolution Rule
Every completed project may contribute lessons back into the Codex, but proposed lessons should be reviewed before becoming permanent standards.
