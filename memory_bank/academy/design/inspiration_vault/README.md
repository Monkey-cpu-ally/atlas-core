# ATLAS Inspiration Vault

## Purpose
The Inspiration Vault turns user-selected visual references into structured design knowledge. It is not a general photo gallery and should not automatically ingest the entire device gallery.

## Primary Interaction
ATLAS HUD uses drag-and-drop as the default ingestion gesture. Traditional buttons should be minimized.

Drop one image, many images, a sketch, blueprint, PDF, or supported design reference onto the ATLAS Core. The system routes the item through analysis and memory indexing.

## Council Analysis
### Minerva
Studies visual composition, color, materials, nature, architecture, symbolism, atmosphere, cultural context, and world-building.

### Hermes
Studies mechanisms, engineering, manufacturing, robotics, electronics, vehicles, structural systems, materials, and functional feasibility.

### Ajani
Studies clothing, silhouette, personal style, luxury, branding, symbolism, product identity, and leadership presence.

### Council
Combines the three analyses, identifies useful relationships, records uncertainty, and proposes original ATLAS applications.

## Design DNA
Every accepted reference can generate a Design DNA record containing:
- source identifier
- media type
- user-selected project context
- detected categories
- objects and systems
- materials
- colors
- shapes
- textures
- functional principles
- aesthetic principles
- possible project connections
- AI observations
- confidence
- source/provenance metadata
- originality constraints

## Memory Behavior
The original reference and the AI's interpretation must remain distinguishable. ATLAS should never convert an inference into a fact.

ATLAS may create semantic links such as:
reference -> mechanical principle -> academy concept -> project -> experiment -> result

## Redesign Workflow
When the user asks ATLAS to redesign a reference:
1. Preserve the user's intent and useful functional principles.
2. Analyze weaknesses and constraints.
3. Search the Design Academy and relevant engineering academies.
4. Minerva proposes material, environmental, artistic, and biomimetic improvements.
5. Hermes proposes engineering, manufacturing, structural, and system improvements.
6. Ajani proposes identity, clothing, luxury, branding, and presentation improvements.
7. Council synthesizes an original ATLAS concept.
8. Save the new concept as a derivative ATLAS project record, not as a replacement for the original reference.

## Privacy Principle
Only content intentionally supplied to ATLAS should enter the Inspiration Vault by default. Personal or unrelated gallery content should remain outside the system unless explicitly selected.

## Originality Principle
References are evidence and inspiration, not templates to copy. ATLAS extracts general principles and combines them with engineering constraints, user requirements, and the ATLAS Design Codex to create original results.
