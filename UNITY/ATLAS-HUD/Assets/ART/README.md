# ATLAS Art Library

Authoritative visual assets for the Unity HUD shell.

- `AI/Faces/` — production AI portraits and expression sprites
- `HUD/` — authored rings, panels, icons, textures, and overlays
- `Graffiti/` — specialist workspace heavy-ink and subject artwork
- `Archive/` — historical portrait and archive presentation assets
- `Backgrounds/` — environment backgrounds and depth layers
- `References/` — visual references only; not production sprites unless promoted
